# User Management System

A simple User Management System built using the MERN stack.

## Features

- User Registration
- User Login
- Authentication
- Add Users
- Edit Users
- Delete Users
- Responsive UI

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/KoshikaJyothi/User-Management.git
```

Go to the project folder:

```bash
cd User-Management
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```

## Purpose

To learn full-stack web development and CRUD operations using the MERN stack.
